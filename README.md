# JAVASCRIPT-PROJECTS
### This ReadMe is to inform all those that view or access this repo, that this repo is for JavaScript projects for The Tech Academy classes.
## Projects
#### Pizza Menu
#### Tic-Tac-Toe Game
#### Calculator
## Pizza Menu
##### This project is a menu used to order pizza with a various selection of toppings. It then takes the input information and calculates a price for the order.
## Tic-Tac-Toe Game
#### The classic game of tic-tac-toe. It alternates between which of the two players goes first and then the game begins. The users faces off against the computer, who randomly selects an empty square. This game features unique sound bytes for actions.
## Calculator
#### A basic, 4-function calculator. Users can add, subtract, multiply, and divide, on a sleek web version of a calculator.
